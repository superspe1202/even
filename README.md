# Even 數位眼鏡

Even（Even Realities）數位眼鏡（智慧眼鏡）相關資料與筆記。

## 用途

存放數位眼鏡的裝置資料、開發筆記與實地應用紀錄，例如：

- 裝置規格、韌體版本與 SDK 筆記
- 配戴操作流程與教學
- 應用構想、整合測試紀錄（如田野調查、資料回報等場景）
- 相關照片、影片與示意圖

## 目錄結構

| 資料夾 | 說明 |
| --- | --- |
| `docs/` | 規格、SDK、操作手冊等文件 |
| `assets/` | 圖片、影片、示意圖等素材 |
| `notes/` | 測試紀錄、會議筆記、待辦想法 |
