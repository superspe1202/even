# 多語言設計

Recipe Glass 支援 8 種語言：`zh`（繁體中文）、`en`、`de`、`fr`、`es`、`it`、`ja`、`ko`
——正好是 Even Hub `app.json` 的 `supported_languages` 允許的全部值。
**手機畫面、眼鏡畫面、內建食譜、AI 產生的食譜、錯誤訊息**都跟著同一個語言。

## 語言怎麼決定

1. 使用者在「設定 → 語言」選了某一種：用它。
2. 選「跟隨手機」（預設）：依 WebView 的 `navigator.languages` 由前到後找，第一個支援的就用；
   **一個都沒有就用英文**。所有 `zh-*`（`zh-TW`、`zh-CN`、`zh-HK`）一律對到繁體中文，因為目前只有這一種中文。
3. 已存的設定值若不是支援的語言（壞資料、舊版本），當作「跟隨手機」。

設定頁會顯示偵測到的手機語言標籤（例如 `ja-JP`），萬一 WebView 回報的跟手機系統不同，
使用者看得出來、也能手動選。切換語言當場生效：手機畫面重畫、眼鏡畫面重排，不必重開 App。

## 程式結構

| 位置 | 內容 |
| --- | --- |
| `src/i18n/zh.ts` | 來源字典（約 250 個字串）。鍵值型別 `MsgKey` 由它推導，其他語言必須齊全，漏一個編譯不過 |
| `src/i18n/{en,de,fr,es,it,ja,ko}.ts` | 各語言字典 |
| `src/i18n/index.ts` | `t(key, params)`、語言偵測、`setLang` / `onLangChange` |
| `src/data/catalog.ts` | 內建食譜**不分語言**的資料：菜系、分類、難易度、份量、時間、每步計時秒數 |
| `src/data/text/<語言>.ts` | 每道菜在該語言的名稱、簡介、食材、步驟、小提醒，用 slug 對應 |
| `src/core/catalog.ts` | 依目前語言組出完整食譜；缺字時 語言 → 英文 → 中文 逐級退回 |

`t()` 支援 `{param}` 代入，以及 `單數|複數`（傳入數字參數 `n` 時依該語言的複數規則選）。

**加入食譜庫是複製。** 使用者按「加入」時，食譜用當時的語言複製一份到自己的庫，
之後換語言不會改動它（那是使用者自己的資料）；眼鏡與手機的外框文字（「· 材料」「步驟 3/8」、操作提示）則照新語言。

## 加一道菜／加一種語言

- **加一道菜**：`catalog.ts` 加一筆（slug、地區、分類、難易度、份量、時間、每步計時秒數），
  每個 `data/text/*.ts` 各加一段。**每種語言的步驟數必須等於計時表長度，小提醒掛在同樣的步驟索引上**
  （檢查腳本會逐項核對）。
- **加一種語言**：`app.json` 的 `supported_languages` 只允許官方清單內的值；
  新增 `i18n/<語言>.ts`、`data/text/<語言>.ts`，在 `i18n/index.ts` 與 `data/text/index.ts` 登記，
  並把它的語言名稱（用該語言自己的寫法）加進 `LANG_NAMES`。

## 品質檢查：`npm run check:i18n`

交付前一定要跑，會檢查：

1. **字典**：每種語言的每個鍵都有值、`{param}` 與 `單數|複數` 結構跟來源一致、沒有殘留的中文或空白。
2. **眼鏡畫面**：待命、完成、響鈴、採購清單空畫面、各種頁尾提示，用 `@evenrealities/pretext` 量真實字寬，
   確認不超過內文 7 行、頁尾不超過一行。
3. **內建食譜**：44 道 × 8 語言，步驟數與計時表一致、小提醒位置一致、
   每一頁都在 7 行內、右欄標籤不換行、標頭放得下（盡量保留時鐘）。
4. **字型缺字**：把所有會顯示在眼鏡上的字元逐一丟給 `getAdvW`，字型沒有的就列出來。
   **G2 韌體遇到缺字是靜默略過**，不會報錯，所以這步是韓文最重要的防線。

## 已知限制與注意事項

- **韓文字型涵蓋有限。** 眼鏡字型的韓文音節只涵蓋一部分（約 2,780 / 11,172 個），
  內建的韓文內容已逐字確認都在範圍內；但 AI 產生的韓文食譜、使用者自己輸入的韓文，
  遇到罕見音節在眼鏡上可能顯示不出來（手機畫面不受影響）。Worker 的提示詞會要求用常見字詞。
- **日文、假名與常用漢字**經檢查都在字型內；罕見漢字（例如人名、古字）同樣可能缺字。
- **進度以畫面索引儲存。** 換語言後文字長度不同，同一步可能分頁數不同；
  在「換語言後又重新開啟 App」的少數情況下，續看位置可能差一頁。
- **WebView 回報的語言可能不等於手機系統語言。** 這時請用設定頁手動選。
- **Worker 要重新部署。** 舊的 Worker 不認得 `lang`，AI 搜尋／匯入的結果仍是繁體中文，
  錯誤訊息也是中文句子；新版 App 配新版 Worker 才會依語言輸出。見 `worker/README.md`。
